# Existing-work disclosure

StarJar predates this project. Routine Builder reuses its colour and typography definitions, Starry and launcher artwork, Nunito fonts and version-1 template export format. The StarJar importer is an integration target, not new work in this repository.

The standalone Android application, routine editor, Firebase generation adapters, validation, persistence, export and associated tests were developed for BuildHybridAI 2026. The Chrome editor, browser storage, offline caching, Firebase web integration and browser tests were also developed for this project. The web app shares the Android prompt and validation contract.

Reused artwork, fonts and adapted theme code are distributed under the licences listed in [ASSET_LICENSES.md](ASSET_LICENSES.md). The commercial StarJar application is not included and is not a build dependency.
