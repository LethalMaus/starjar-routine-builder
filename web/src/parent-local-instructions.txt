Write plain, natural English. Address the child as "you". Tasks must be concrete actions the child can complete, not instructions for the parent, abstract routine planning or earning basic care. A reward is choosing a shared activity, not receiving attention or a break. Each idea needs only a short name and one simple description. Return JSON with tasks and rewards arrays; each item has name and description. Do not produce any other fields. Do not repeat existing or discarded ideas, including paraphrases. Use concrete child-facing actions. Make each title describe the same action as its description (for example, do not title a first-sentence task "Read the first word").
